# 🚀 Quick Start with FREE Google Gemini AI

## Get AI Working in 2 Minutes!

### Step 1: Get FREE Gemini API Key (30 seconds)
1. Visit: **https://aistudio.google.com/app/apikey**
2. Click "Get API Key" or "Create API key"
3. Copy the key (starts with `AIza...`)

### Step 2: Add to Your App (30 seconds)
Open `.env` file and paste your key:

```env
GOOGLE_GEMINI_API_KEY=AIzaSyC_YOUR_KEY_HERE
AI_DEFAULT_PROVIDER=gemini
```

### Step 3: Done! ✅
Restart the server and AI question generation will work!

```bash
npm run server
```
