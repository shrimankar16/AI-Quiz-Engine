│  🚀 QUICK START (3 STEPS)                                               │
└─────────────────────────────────────────────────────────────────────────┘

STEP 1: Install Dependencies
───────────────────────────
npm install


STEP 2: Setup MySQL Database
────────────────────────────
1. Open MySQL:
   mysql -u root -p

2. Create database:
   CREATE DATABASE quizforge;
   EXIT;

3. Update .env file with your MySQL password:
   DATABASE_URL="mysql://root:YOUR_PASSWORD@localhost:3306/quizforge"

4. Run migrations:
   npx prisma migrate dev --name init


STEP 3: Start Application
──────────────────────────
npm run dev

✅ Frontend: http://localhost:5173
✅ Backend:  http://localhost:3000

┌─────────────────────────────────────────────────────────────────────────┐
│  👥 HOW TO USE THE APPLICATION                                          │
└─────────────────────────────────────────────────────────────────────────┘

AS A TEACHER:
─────────────
1. Register at http://localhost:5173/register (select "Teacher")
2. Login to teacher dashboard
3. Click "Create Exam" button
4. Add exam details (title, description, duration, passing score)
5. Click "Manage" to add questions
6. Add questions (3 types available):
   - Multiple Choice (4 options)
   - True/False
   - Short Answer
7. Click "Publish" to make exam available
8. Share the 9-digit access code with students
9. View results and statistics after students complete

AS A STUDENT:
─────────────
1. Register at http://localhost:5173/register (select "Student")
2. Login to student dashboard
3. Enter the 9-digit access code from your teacher
4. Click "Join" to access the exam
5. Take the exam (timer will countdown)
6. Answers auto-save as you type
7. Click "Submit Exam" when done
8. View instant results with detailed feedback

┌─────────────────────────────────────────────────────────────────────────┐
│  🔌 API ENDPOINTS                                                       │
└─────────────────────────────────────────────────────────────────────────┘

AUTH
POST   /api/auth/register         Register new user
POST   /api/auth/login            Login
POST   /api/auth/logout           Logout
POST   /api/auth/forgot-password  Request password reset
POST   /api/auth/reset-password   Reset password
GET    /api/auth/me               Get current user

TEACHER
GET    /api/teacher/exams                              List all exams
POST   /api/teacher/exams                              Create exam
GET    /api/teacher/exams/:id                          Get exam details
PUT    /api/teacher/exams/:id                          Update exam
DELETE /api/teacher/exams/:id                          Delete exam
POST   /api/teacher/exams/:id/publish                  Toggle publish
POST   /api/teacher/exams/:examId/questions            Add question
DELETE /api/teacher/exams/:examId/questions/:qId       Delete question
GET    /api/teacher/exams/:examId/results              View submissions
GET    /api/teacher/exams/:examId/statistics           Get statistics

STUDENT
GET    /api/student/dashboard/stats              Dashboard stats
POST   /api/student/access-code                  Join exam with code
GET    /api/student/exams/:examId                Get exam details
POST   /api/student/exams/:examId/start          Start attempt
PUT    /api/student/attempts/:attemptId/answers  Save answers
POST   /api/student/attempts/:attemptId/submit   Submit exam
GET    /api/student/attempts/:attemptId          Get results
GET    /api/student/exams/:examId/leaderboard    View leaderboard

┌─────────────────────────────────────────────────────────────────────────┐
│  🐛 TROUBLESHOOTING                                                     │
└─────────────────────────────────────────────────────────────────────────┘

DATABASE CONNECTION ERROR
→ Check MySQL is running
→ Verify DATABASE_URL in .env
→ Ensure database "quizforge" exists

PORT ALREADY IN USE
→ Change PORT in .env (backend)
→ Kill process using port: taskkill /F /IM node.exe (Windows)

DEPENDENCIES ERROR
→ Delete node_modules and package-lock.json
→ Run: npm install

PRISMA ERROR
→ Run: npx prisma generate
→ Run: npx prisma migrate dev

FRONTEND NOT LOADING
→ Check if both servers are running
→ Verify VITE_API_URL in client/.env
